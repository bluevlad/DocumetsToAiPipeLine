# DocumetsToAiPipeLine Documentation

## Directory Structure

```
docs/
├── README.md                    # 이 파일
│
├── dev/                         # 개발자 가이드
│   ├── SETUP.md
│   └── EMBEDDING_AND_LLM_OPTIONS.md
│
├── adr/                         # Architecture Decision Records
├── api/                         # API 변경 이력
└── roadmap/                     # 로드맵
```

## Directory Descriptions

| 디렉토리 | 용도 | 대상 |
|-----------|------|------|
| `dev/` | 개발/배포 환경 설정·옵션 | 개발자 |
| `adr/` | 아키텍처 결정 기록 | 개발자 |
| `api/` | API 변경 이력 | 개발자 |
| `roadmap/` | 기능 로드맵 | 개발자/PM |

> 분석 대상 문서에서 파생된 산출물(요구사항 추출본, 레거시 분석, 프로젝트 이력 등)은
> 개인·고객사 자료를 포함하므로 별도 private 저장소에서 관리합니다.
